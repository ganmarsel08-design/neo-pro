# Тесты НеоДневника

Только синтетические данные: выдуманные фамилии, даты, показатели. Реальных пациентов и токенов в тестах нет.

```
npm ci                                   # esbuild и prettier фиксированных версий
pip install -r tests/requirements.txt && python -m playwright install chromium
python -m pytest tests -q                # все тесты на текущем index.html
NEO_INDEX=путь/к/index.html python -m pytest tests/test_audit.py   # на другой сборке
python tests/audit_matrix.py origin/main # таблица «до/после» по дефектам AUDIT.md
```

| Файл | Что проверяет |
|---|---|
| `test_static.py` | сборка из `src/` совпадает с `index.html`; 29 протоколов не изменены (хэш в `protocols.sha256`); цитаты РК дословны; известный дефект синхронизации |
| `test_audit.py` | дефекты AUDIT.md: переполнение памяти, QR медсестры, «без динамики», приём смены, предупреждение о незашифрованном коде; открытый дефект дублей при приёме смены |
| `test_dictation.py` | диктовка: ребёнок и время для каждой фразы, двойни, похожие фамилии, подтверждение перед записью |
| `test_express.py` | правила-кандидаты «Антидефекта» не блокируют дневник |
| `test_express_day.py` | дневник за сутки: будущие интервалы — черновики, план ≠ факт, подтверждение врачом, смена 08:30–08:30 |

Тесты с `xfail(strict=True)` — воспроизведённые, но ещё не исправленные дефекты. Когда дефект исправят, тест «неожиданно пройдёт» и CI попросит снять отметку. Ослаблять тесты ради зелёного CI нельзя.
